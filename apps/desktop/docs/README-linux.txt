OMNIServers for Linux
=====================
Free and open source (GPL-3.0). No account needed.

Run:    tar xzf OMNIServers-*-linux-x64.tar.gz && ./omniservers
Needs:  a desktop session (X11 or Wayland) and these libraries: libfontconfig1, libx11-6, libice6, libsm6.
        Debian/Ubuntu: sudo apt install libfontconfig1 libx11-6 libice6 libsm6
Data:   ~/.config/CraftPanel (servers, settings) and ~/.local/share/CraftPanel (Java runtimes).

Status: this is the first Linux build. It has not been tested on a real Linux desktop yet.
Not yet on Linux: the built-in tunnel, the firewall helper and in-app updates.
Help:   https://discord.gg/SQwCjE38Jt
